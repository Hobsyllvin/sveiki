# voice-test — Jānis voice audition

Not lesson content. This short reel isolates Jānis's proposed voice in neutral,
curious, warm, and reflective delivery before it is used in lesson 1.

Run with:

    npm run audio -- --script content/lv/audio-scripts/voice-test.md

The speaker name must match the key in `content/lv/voices.json`. Output goes to
`content/lv/audio-elevenlabs/voice-test.*`.

s1 | Jānis | Mani sauc Jānis. Es mācos latviski.
s2 | Jānis | [curiously] Kā tevi sauc?
s3 | Jānis | [warmly] Prieks iepazīties!
s4 | Jānis | [thoughtfully] Es vēl nerunāju ļoti labi, bet es jau daudz saprotu.
